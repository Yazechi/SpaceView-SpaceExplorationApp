In this Project we are going to make a web application about Space Exploration. The application will provide users with information about various space missions, astronauts, and celestial bodies.

We can rely on the free API that is being provided by NASA: https://api.nasa.gov/
Main feature that must be included in the application:
1. Display a list of past and current space missions with details such as mission name, launch date, and mission status.
2. Provide detailed profiles of astronauts, including their biographies, missions they have participated in, and photos.
3. Include a section dedicated to celestial bodies (planets, moons, asteroids) with interesting facts and images.
4. Implement a search functionality that allows users to search for missions, astronauts, or celestial bodies.
5. Create an interactive timeline of significant events in space exploration history.
6. Ensure the application is responsive and works well on both desktop and mobile devices.
7. A 3d preview of the solar system where users can click on planets to get more information about them.


Project Instructions:
1. Choose a modern web development framework (e.g., React, Angular, Vue) to build the application.
2. Set up the project structure and install necessary dependencies.
3. Integrate with the NASA API to fetch data for missions, astronauts, and celestial bodies
4. Design and implement the user interface, ensuring a user-friendly experience.
5. Implement the search functionality to filter through missions, astronauts, and celestial bodies.
6. Develop the interactive timeline feature to showcase significant events in space exploration.
7. Use a 3D library (e.g., Three.js) to create the solar system preview.
8. Test the application thoroughly to ensure all features work as expected.
9. Make sure to not use Emojis and excessive exclamation marks in the code comments and documentation.


For suggestions on code style and best practices, please refer to the following guidelines:
1. Follow the standard coding conventions for the chosen framework (e.g., React's JSX syntax, Angular's TypeScript style guide).
2. Use meaningful variable and function names to enhance code readability.
3. Keep components modular and reusable to promote maintainability.
4. Avoid using inline styles; instead, use CSS or styled-components for styling.
5. Handle API errors gracefully and provide user feedback when data cannot be fetched.
6. Write comments to explain complex logic, but avoid over-commenting obvious code.
